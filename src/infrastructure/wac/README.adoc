= wac

Web Access Control (WAC) implementation for Solid resources.
WAC is the Solid authorization protocol where permissions are stored in `.acl` files alongside resources.

The link:../../features/sharing/hooks/useAclManager/[useAclManager] hook in `features/sharing` provides the React interface on top of this module.

== Contents

link:aclManager/[aclManager]:: Discover ACL document URIs from `Link` headers, read current agents, and write new ACL documents
link:aclSnapshot/[aclSnapshot]:: Copy an ACL document verbatim to a snapshot URI and restore it later, for soft delete/restore
link:wacAllow/[wacAllow]:: Parse the `WAC-Allow` response header to preflight-check delete permission
