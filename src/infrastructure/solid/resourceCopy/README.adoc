= resourceCopy

GET-then-PUT copy of a single Solid resource (`copyResource`), tolerant container creation (`ensureContainer`), and a recursive whole-tree copy (`copyContainerTree`). One implementation for both binaries and Turtle documents.

`copyResource` takes the target's content type from the source response's `Content-Type` header, falling back to a caller-supplied default, then `application/octet-stream`.

`ensureContainer` PUTs an empty Turtle body and treats 409 (already exists) as success, matching how Community Solid Server creates containers.

`copyContainerTree` mirrors a source container's whole subtree to the same relative paths under a target root, reading the live pod tree rather than catalog data, so uncatalogued files and subfolders come along too. It throws instead of trusting a malformed listing: a child outside its own container, or a container that lists itself again.
