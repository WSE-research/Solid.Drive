= catalog

DCAT catalog operations for Solid Pods, using raw `fetch` instead of LDO
for every request. URIs passed to SPARQL operations are checked for unsafe
characters before interpolation.

== Exports

[cols="1,3", options="header"]
|===
| Name | Description

| `resolveCatalogUri(profile, storageRoot)` | Returns the profile's catalog address if it has one, otherwise the default under the storage root
| `appendToCatalog(params)` | Adds a file's dataset and distribution entry via SPARQL PATCH, creating the catalog first if it doesn't exist. Types the entry as both `dcat:Dataset` and `sd:File`, and writes `sd:hasParent` when `params.parentUri` is non-empty
| `appendFolderToCatalog(params)` | Adds a folder's dataset entry (no distribution) via SPARQL PATCH, creating the catalog first if it doesn't exist. Always writes `sd:hasParent`, and types the entry as both `dcat:Dataset` and `sd:Folder`
| `ensureCatalogRootEntry(params)` | Registers the pod's storage root as its own parentless catalog entry, the terminator every folder path walk reaches. Safe to call repeatedly: its triples never vary, so re-inserting them is a no-op
| `isFolderEntry(entry)` | True when a `CatalogEntry` is a folder, whether marked with the current `sd:Folder` class or the legacy `ldp:Container` marker
| `FOLDER_CLASS_URI` | The `dcterms:conformsTo` / `rdf:type` value (`sd:Folder`, from this project's own catalog vocabulary) that marks a catalog entry as a folder
| `FILE_CLASS_URI` | The `sd:File` value `appendToCatalog` types every file entry with. Descriptive only, nothing routes on it
| `LEGACY_FOLDER_CLASS_URI` | The `ldp:Container` marker folders were written with before `sd:Folder` existed; `isFolderEntry` still recognizes it
| `removeFromCatalog(...)` | Removes a dataset entry via SPARQL DELETE WHERE, doing nothing if the catalog isn't reachable
| `parseCatalog(turtleText, baseUri?)` | Parses a Turtle catalog into a list of `CatalogEntry` objects, including each entry's `parentUri` from `sd:hasParent`
| `linkCatalogToProfile(catalogUri, webId, fetch)` | Adds a `dcat:catalog` triple to the user's profile document
| `buildEmptyCatalogTurtle(catalogUri)` | Turtle template for a new, empty catalog, with an explicit `@base` so the document identifies itself outside its own retrieval context
|===

The vocabulary (`sd:StorageObject`, `sd:Folder`, `sd:File`, `sd:hasParent`, `sd:deletedAt`) is defined in `public/vocab/solid-drive-catalog.ttl`, published under the `https://purl.org/solid-drive/catalog#` PURL. `sd:deletedAt` is defined there but not yet written by this module.
