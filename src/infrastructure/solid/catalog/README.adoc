= catalog

DCAT catalog operations for Solid Pods, using raw `fetch` instead of LDO
for every request. URIs passed to SPARQL operations are checked for unsafe
characters before interpolation.

== Exports

[cols="1,3", options="header"]
|===
| Name | Description

| `resolveCatalogUri(profile, storageRoot)` | Returns the profile's catalog address if it has one, otherwise the default under the storage root
| `appendToCatalog(...)` | Adds a file's dataset and distribution entry via SPARQL PATCH, creating the catalog first if it doesn't exist
| `appendFolderToCatalog(...)` | Adds a folder's dataset entry (no distribution) via SPARQL PATCH, creating the catalog first if it doesn't exist
| `FOLDER_CLASS_URI` | The `dcterms:conformsTo` value (`ldp:Container`) that marks a catalog entry as a folder instead of a file
| `removeFromCatalog(...)` | Removes a dataset entry via SPARQL DELETE WHERE, doing nothing if the catalog isn't reachable
| `parseCatalog(turtleText, baseUri?)` | Parses a Turtle catalog into a list of `CatalogEntry` objects
| `linkCatalogToProfile(catalogUri, webId, fetch)` | Adds a `dcat:catalog` triple to the user's profile document
| `EMPTY_CATALOG_TURTLE` | Minimal Turtle template for a new, empty catalog
|===

== See also

* link:../../features/file-explorer/hooks/useFileUpload/[useFileUpload] calls `appendToCatalog` and `linkCatalogToProfile` from this module during the upload sequence.
* link:../../features/file-explorer/hooks/useCreateFolder/[useCreateFolder] calls `appendFolderToCatalog` and `linkCatalogToProfile` when a folder is created.

* link:../../features/file-explorer/hooks/useSharedCatalog/[useSharedCatalog] calls `parseCatalog` from this module to read both the shared and main catalog documents.
