= fileFilter

Determines which resources should be visible in the file explorer.

== Functions

`isVisibleLeaf(entry)` / `isVisibleResourceUri(uri)`:: Returns `false` for files in the `SYSTEM_FILES` set (`catalog.ttl`, `robots.txt`, `.acl`, `.meta`, `README`) and shared catalog files matching the `.shared-*.ttl` pattern. Keeps Solid's own plumbing files out of the file browser.
`isVisibleContainer(entry)` / `isVisibleContainerUri(uri)`:: Returns `false` for the trash container (`TRASH_CONTAINER_NAME`). It's a real, plainly-named Solid container, so any generic pod browser can inspect it. This app just keeps it out of the regular My Files listing; it's reachable through the dedicated Recycle bin view instead.
