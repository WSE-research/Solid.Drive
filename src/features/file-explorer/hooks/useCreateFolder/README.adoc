= useCreateFolder

Creates a new folder in the Pod and registers it in the catalog, so it has a
real address and shows up under the name the user actually typed.

== Validation

`validateName` checks a folder name and returns an error key, or `null` if the name is fine.

Rejects:

* An empty name, after trimming whitespace
* A name containing any of `/  \  :  *  ?  "  <  >  |`

== Creating a folder

`createFolder` builds the folder's address from its name and creates it, then
saves the typed name as the folder's catalog title.

If saving the catalog title fails, the folder is deleted so nothing gets left
behind without a name, and the failure is thrown. If saving succeeds, every
other part of the app watching the catalog picks up the new folder right
away, no manual refresh needed.

If creating the folder itself fails, that error is thrown too; the caller is responsible for catching it.

== Parameters

`createFolder` takes:

[cols="1,1,3", options="header"]
|===
| Parameter | Type | Description

| `parentContainer`   | `SolidContainer` | The folder the new one is created inside
| `folderName`        | `string`         | The name the user typed
| `catalogUri`        | `string`         | Address of the catalog to register the new folder in
| `profileHasCatalog` | `boolean`        | Whether the user's profile already links to that catalog
|===

== Returns

[cols="1,1,3", options="header"]
|===
| Key | Type | Description

| `isCreating`   | `boolean` | True while a folder is being created
| `createFolder` | function  | Creates a folder and resolves to its address
| `validateName` | function  | Checks a folder name and returns an error key, or `null` if it's fine
|===
