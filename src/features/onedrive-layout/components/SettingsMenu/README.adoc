= SettingsMenu

Gear-icon dropdown in the OneDrive topbar.
Hosts Radix sections separated by dividers: the language radio group, the theme select, and the color scheme select. The theme select also carries the option to drop back to the classic shell.

Stateless composition.
The language section reads / writes through `react-i18next`; the theme section delegates to link:../ThemeToggle/[ThemeToggle].
