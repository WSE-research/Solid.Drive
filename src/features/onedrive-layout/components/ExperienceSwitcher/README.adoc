= ExperienceSwitcher

Dropdown in the classic header that switches the whole look: `Classic`, `OneDrive (Light)`, `OneDrive (Dark)`, `Dropbox` or `Google Drive`.
Picking a theme entry moves both preferences at once, so the user reaches any theme from the classic shell in one interaction instead of switching layout first and then opening the OneDrive Settings menu.

Rendered as a plain `<select>`: it sits beside the language switcher in the classic header and inherits the same global control styling, and it stays one control wide however many themes ship.
The signed-in OneDrive shell offers the same flat list through its own Settings dropdown (link:../ThemeToggle/[ThemeToggle]); this switcher is the classic header's equivalent.

The option list is derived from `EXPERIENCES` and the labels are a `Record<Experience, string>`, so adding a theme to the union makes TypeScript demand a label rather than silently leaving the switcher one option short.

Stateless wrapper around link:../../hooks/useExperiencePreference/[useExperiencePreference], which owns the translation between the one experience value and the two stored preferences.
