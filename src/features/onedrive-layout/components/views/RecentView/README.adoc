= RecentView

Home / Recent view for the OneDrive layout.

Reads the user's DCAT catalog, sorts entries by `modified` desc, and renders the 10 most recent in a flat Name / Opened / Owner table that mirrors the OneDrive Home recent section. Shows a spinner on the first, empty load; a background revalidation after that keeps the table showing its last-known rows (see useCatalog's stale-while-revalidate behavior).

The inline toolbar above the table carries the heading, the type chips derived from the catalog's observed schema.org classes, and a person and name filter input.
The heading uses the shared `.odl-page-title` sizing.

The chip row uses the inline chips above 1200px, the `TypeFilterChipsDropdown` ("All ▼") between 381 and 1200px, and icon-only inline chips below 381px.

All filter, search, and sort state lives in link:../../../hooks/useRecentFilters/[useRecentFilters].

Clicking a row, or activating it with Enter or Space, opens the same full-screen preview dialog used for shared files, filled in with that row's file, title, and type. Download works the same way it does everywhere else in the app.

== Internal pieces

* `RecentFilesTable` renders the flat Name / Opened / Owner rows.
