= ThemeToggle

Dropdown that switches the active theme: `Light`, `Dark` or `Dropbox`.
The trigger shows the current value with a chevron; the `Theme` heading above it is rendered by the TopBar's Settings menu.
Mounted inside that Settings dropdown above the LayoutToggle.

The option list is derived from `THEMES` and the labels are a `Record&lt;Theme, string&gt;`, so adding a theme to the union makes TypeScript demand a label rather than silently leaving the picker one option short.

Stateless wrapper around link:../../hooks/useThemePreference/[useThemePreference].
The hook owns the value, mirrors it onto `document.documentElement` as `data-theme`, and writes to `localStorage`.
