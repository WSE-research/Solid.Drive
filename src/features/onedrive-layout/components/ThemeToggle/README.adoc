= ThemeToggle

Dropdown that switches the active experience: `Classic`, `Light`, `Dark`, `Dropbox` or `Google Drive`.
The trigger shows the current value with a chevron; the `Theme` heading above it is rendered by the TopBar's Settings menu.
Picking a theme keeps the OneDrive shell mounted and restyles it; picking `Classic` drops back to the classic shell.

The option list is derived from `EXPERIENCES` and the labels are a `Record<Experience, string>`, so adding a theme to the union makes TypeScript demand a label rather than silently leaving the picker one option short.

Stateless wrapper around link:../../hooks/useExperiencePreference/[useExperiencePreference].
The hook owns the value, translating it into the underlying layout and theme preferences.
