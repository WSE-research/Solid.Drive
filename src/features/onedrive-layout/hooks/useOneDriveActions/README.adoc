= useOneDriveActions

Action handlers for the OneDrive shell that depend on the current selection.
Owns the toast wiring and the delete confirmation prompts so `OneDriveLayout` is reduced to composition.

== Arguments

[cols="1,3", options="header"]
|===
| Field | Description

| `selected` | Current selection from link:../useSelectedResource/[useSelectedResource]
| `catalogByContainer` | `Map<containerUri, CatalogEntry>` from `OneDriveLayout`
| `catalogUri` | URI of the owner's DCAT catalog. Needed for catalog cleanup on delete.
| `solidFetch` | Authenticated Solid fetch
| `onAfterDelete` | Fired after a successful delete so the shell can clear the selection and close the panel
| `storageRootUri` | Pod storage root. Required for soft delete — the trash lives here, not under the app container; folders always hard-delete regardless.
| `entry` | The selection's catalog-row payload (`OneDriveLayout`'s `sharedEntry` memo), passed through to `softDeleteFile`.
| `ownerWebId` | WebID used as the trash catalog entry's publisher.
|===

== Returns

[cols="1,3", options="header"]
|===
| Field | Description

| `handleCopyLink` | Copies the selection URI to the clipboard and toasts the result
| `handleDownload` | Downloads the file binary, toasts on failure
| `handleDelete` | Moves a file to the Recycle bin when `storageRootUri`/`entry`/`catalogUri`/`ownerWebId` are all resolved; hard-deletes otherwise (always for folders, since they aren't catalog-backed and can't be tombstoned)
|===

`handleDelete` decides *what* to run, soft-delete or hard-delete, and hands it to link:../../../file-explorer/hooks/useGuardedSoftDelete/[useGuardedSoftDelete], which owns the re-entrancy lock, the confirm dialog, and the toast. `FileCard` uses the same shared hook for its own delete actions.

Permanently deleting a file bypasses the Recycle bin only from inside it (the trash view's own purge action, see link:../../../file-explorer/hooks/useTrashEntries/[useTrashEntries]) — `SelectionActions` in My Files offers a single delete action, which always lands in the Recycle bin for files.
